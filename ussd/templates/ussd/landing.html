State Machine Architecture

Every Fault Has a Clear Lifecycle

Zero ambiguity. State transitions are tracked second-by-second to eliminate lost tickets and measure mean-time-to-repair (MTTR).

OPEN

1. Logged via USSD

Created by worker on factory floor. Awaiting supervisor triage.

ASSIGNED

2. Tech Dispatched

Supervisor selects technician. Automated SMS dispatched via AT.

ACCEPTED

3. Tech Confirmed

Technician acknowledges incident via two-way SMS reply.

IN_PROGRESS

4. Active Repair

Technician is on site actively executing machine repairs.

RESOLVED

5. Verified Fixed

Maintenance completed. Machine restored to operational uptime.

💡 Every state transition records timestamps, user IDs, and machine status—empowering plant managers with automated uptime analytics.

Industrial Realities FAQ

Frequently Asked Questions

Common technical and operational questions from plant managers and hackathon evaluators.

Factory floors are filled with metallic shielding, heavy motors, and concrete walls where 4G/5G and Wi-Fi fail. Furthermore, workers frequently carry basic feature phones or cannot install third-party apps with personal data bundles. USSD operates over standard cellular signaling channels with 100% reach on any phone, zero data cost, and instant menu responsiveness.
When assigned a task, technicians receive an automated SMS with the machine name, problem, severity, and ticket ID. Technicians can simply reply with ACCEPT <ID> to confirm or mark the task completed upon repair. Africa's Talking routes this reply back into FactoryPulse webhooks to update the dashboard instantly.
All incoming webhooks (USSD callbacks and SMS delivery receipts) are verified using secure HMAC tokens and IP verification against Africa's Talking gateway headers. Requests missing valid authentication signatures are immediately rejected.
Every fault report captures exact millisecond timestamps at creation (OPEN), assignment (ASSIGNED), technician acknowledgment (ACCEPTED), work start (IN_PROGRESS), and completion (RESOLVED). This provides actionable Mean Time to Detect (MTTD) and Mean Time to Repair (MTTR) analytics to plant supervisors.
